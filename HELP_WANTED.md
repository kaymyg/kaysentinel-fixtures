# Help wanted

Kaysentinel Fixtures is open to contributions. Below is the hardening work that would make it stronger, roughly in order of impact. Pick anything, comment on (or open) an issue so others know you are on it, and see [CONTRIBUTING.md](CONTRIBUTING.md) to get started.

Found a vulnerability instead? Please report it privately, see [SECURITY.md](SECURITY.md).


### Fixtures for new EIPs

**Good first issue.** Add fixtures for recently activated EIPs, following the existing folder layout.

### JSON Schema validation in CI

**Medium.** A schema for fixture files and a CI step that validates every fixture against it.
